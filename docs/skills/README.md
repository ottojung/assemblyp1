# Research skills

These guides are the operational playbooks for AI-assisted research in assemblyp1. Start with [`research-orchestrator.md`](research-orchestrator.md) for substantial work; use the narrower skills for delegated packets.

- [`research-orchestrator.md`](research-orchestrator.md) — choose the frontier, decompose work, delegate, reconcile, verify, and integrate.
- [`literature-search.md`](literature-search.md) — recover exact source definitions, theorem statements, later citations, and unresolved semantics.
- [`formalization.md`](formalization.md) — translate stable mathematical objects and propositions into Lean without changing the target.
- [`proof-search.md`](proof-search.md) — decompose conjectures, derive lemmas, and keep positive proof search disciplined.
- [`counterexample-search.md`](counterexample-search.md) — perform bounded finite search, symmetry reduction, witness minimization, and certificate production.
- [`reconciliation.md`](reconciliation.md) — compare partial outputs, resolve assumption mismatches, and maintain the research dependency graph.
- [`scheduled.md`](scheduled.md) — reusable mechanics for recurring scheduled work.
- [`itinerary-assemblyp1.md`](itinerary-assemblyp1.md) — **canonical sole entry point** for AssemblyP1 scheduled work; owns project-specific work selection, integration, verification, and completion policy.

The conceptual protocol shared by all of these skills is [`../research-orchestration.md`](../research-orchestration.md).
