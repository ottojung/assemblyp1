# Research skills

These guides are the operational playbooks for AI-assisted research in assemblyp1. Start with `research-orchestrator.md` for substantial work; use the narrower skills for delegated packets.

- `research-orchestrator.md` — choose the frontier, decompose work, delegate, reconcile, verify, and integrate.
- `literature-search.md` — recover exact source definitions, theorem statements, later citations, and unresolved semantics.
- `formalization.md` — translate stable mathematical objects and propositions into Lean without changing the target.
- `proof-search.md` — decompose conjectures, derive lemmas, and keep positive proof search disciplined.
- `counterexample-search.md` — perform bounded finite search, symmetry reduction, witness minimization, and certificate production.
- `reconciliation.md` — compare partial outputs, resolve assumption mismatches, and maintain the research dependency graph.
- `scheduled.md` — durable mechanics for recurring scheduled work.
- `itinerary-assemblyp1.md` — project-specific work selection and completion policy for scheduled invocations.

The conceptual protocol shared by all of these skills is `../research-orchestration.md`.
