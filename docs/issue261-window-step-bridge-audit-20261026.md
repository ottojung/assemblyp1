# Issue #261: window-to-edge bridge audit (2026-10-26)

## Bounded result

The current Section 6.2 Lean model has a precise local bridge obligation, but
does not yet prove a circular-window-to-edge map. `Spelling.step` in
`AssemblyP1/Section62BidirectedFlow.lean` constructs an edge from the abstract
strands at adjacent positions using overlap length `readLen - 1`. The
`overlapEdges` definition admits that edge exactly when the suffix/prefix
content equality holds, its length is in the range generated by
`List.range readLen`, the length is at least `oMin`, and both strands are among
`strandsOf rc verts`.

Therefore the *unreduced* graph availability argument, once its premises are
supplied, has only these obligations for each cyclic position `i`:

1. `oMin ≤ readLen - 1`;
2. `readLen - 1 < readLen` (for nonzero `readLen`);
3. the concrete words at `sp.strand i` and `sp.strand (next sp i)` have matching
   suffix/prefix of length `readLen - 1`;
4. both strands occur in the enumerated observed molecule representatives or
   their reverse complements.

The present `Spelling` contains only `strand : Fin n → W` and `hn : 0 < n`.
It has no content map `W → List A`, no equation identifying its strands with
consecutive circular windows, and no membership evidence in `verts`. Thus 3
and 4 cannot be derived from its type. `SpelledFeasible62` correctly keeps
`StepsInGraph` and `StepsSurviveReduction` as explicit independent premises;
neither follows from the current `Spelling` record.

## Scope and source boundary

This is a definition audit, not a counterexample to MB09 and not a theorem about
all genuine circular genomes. It identifies the exact missing input needed for
the conditional implication to arbitrary `o_min ≤ readLen - 1`. Even after the
unreduced membership lemma, survival under `transitivelyReduced` remains a
separate requirement and must not be silently inferred. The physical-orbit
loop half-incidence result in `Section62PhysicalEdgeOrbit.ForwardLoop` is local
to an already-given tagged edge and supplies none of these content or graph
membership premises.

Candidate classes and transfer boundary remain: MB09 feasible flows versus
spelled circuits versus circular genomes are distinct unless an explicit
inclusion is proved. No likelihood or maximality transfer is asserted here.

Extend the spelling/window interface with source-faithful data: a content

for `oMin ≤ readLen - 1`; separately investigate whether the particular
