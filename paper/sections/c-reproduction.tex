\section{Reproducing the results}
\label{app:reproduction}

The build and proof index are maintained alongside the paper:
\texttt{paper/README.md} gives the TeX build instructions and
\path{docs/verification.md} maps claims to full Lean declarations,
hypotheses and independent scripts.

From the repository root the reproducible paper build is
\begin{verbatim}
sh paper/build.sh
\end{verbatim}
This uses the packages specified in \texttt{paper/manifest.scm} and
runs \texttt{latexmk} with \texttt{biber}. The repository's
\texttt{paper/README.md} describes an alternative Guix-shell build
and the verification workflow.

The unconditional population-uniqueness theorem and its distinction
from the earlier conditional Eulerian-obstruction interface are
explicitly indexed in \path{docs/verification.md}.
That file also distinguishes finite computations from kernel-checked
results and historical source premises.
